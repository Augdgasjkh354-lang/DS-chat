# DS Chat

安卓聊天 App（Kotlin + Jetpack Compose），包名 `com.jack.dschat`。

接的是 DeepSeek 开放平台的 API（`deepseek-flash`，Chat Completions 流式接口）。第一次用先在 设置 → API Key 填上自己的 Key（[开放平台](https://platform.deepseek.com/api_keys) 创建），保存时会查一下余额确认能用。

- 对话：流式输出（每秒 100 字匀速放出、末尾淡入，写完一两秒内收尾；列表平滑跟随，往上翻时不拽回，有「回到底部」按钮）、深度思考（可折叠）、停止、重新生成、复制、Markdown 显示（标题、列表、代码块、表格等；表格按内容定列宽、支持对齐；有序列表编号圆圈、「**小标题**：说明」拆行、裸网址可点）、LaTeX 公式（`$…$`、`\(…\)`、`$$…$$`、`\[…\]`，本地用 JLaTeXMath 画）
- 智能搜索：用官方的 `deepseek_web_search`，搜索在 DeepSeek 服务端跑；回答下面列出引用的网页，点开用浏览器看
- 读链接：消息里贴网址，模型会自己去读（`deepseek_read_url`，一直开着）
- 自动标题：新对话的标题由模型顺手起
- 侧边栏：历史记录按时间分组、搜索、重命名、删除、多选删除
- 角色扮演：侧边栏「角色扮演」。角色卡有名字、头像、人设、开场白、性格、场景、示例对话、额外要求和创意度（temperature）；内置 4 个原创示例角色；能导入「酒馆」（SillyTavern）的 PNG / JSON 角色卡（V1 / V2 / V3）；「我的设定」所有角色都知道。角色对话默认不带工具（带工具时创意度不生效），深度思考、联网按对话单独开关
- 长期记忆：角色对话里没整理的部分超过约 2.4 万字时，把最近 16 条以前的内容让模型整理成「前情回忆」，之后只发回忆 + 最近对话；顶栏点角色名能看、能改、能马上整理
- 导入历史对话：设置 → 数据管理 → 导入 DeepSeek 历史对话，选官方 App / 网页「导出所有历史对话」得到的 `deepseek_data-*.zip`（格式 v3，照 DeepSeek 开源的 chat-demo）。合并进现有对话，同一对话再导入会更新；分支只留最后停留的那条线；图片、文件只留文件名；出错、被拒的轮次不进上下文
- 设置：API Key、外观（系统 / 浅色 / 深色）、字体大小、语言（简体中文 / English）、清空对话
- 个性化：自定义聊天背景图，可调遮罩浓度和模糊（模糊要 Android 12 以上）

还没做：语音输入（ASR）、朗读（TTS）、上传文件和图片。DeepSeek 2026-11-13 已经开放了这些接口，下一步接。
