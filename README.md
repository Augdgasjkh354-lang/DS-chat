# DS Chat

安卓聊天 App（Kotlin + Jetpack Compose），包名 `com.jack.dschat`。

接的是 DeepSeek 开放平台的 API（`deepseek-flash`，Chat Completions 流式接口）。第一次用先在 设置 → API Key 填上自己的 Key（[开放平台](https://platform.deepseek.com/api_keys) 创建），保存时会查一下余额确认能用。

- 对话：流式输出（每秒 100 字匀速放出、末尾淡入，写完一两秒内收尾；列表平滑跟随，往上翻时不拽回，有「回到底部」按钮）、深度思考（可折叠）、停止、重新生成、复制、Markdown 显示（标题、列表、代码块、表格等；表格按内容定列宽、支持对齐；有序列表编号圆圈、「**小标题**：说明」拆行、裸网址可点）、LaTeX 公式（`$…$`、`\(…\)`、`$$…$$`、`\[…\]`，本地用 JLaTeXMath 画）
- 多版本回复：最后一条回复点「重新生成」会多出一版，旧的留着；回复下面「‹ 2 / 3 ›」或在回复上左右滑切换，发给模型的是正在看的那一版
- 发图片：输入框的「+」从相册选（一次最多 9 张），缩到长边 1600 存在本机；先传到 DeepSeek Files API（30 天有效，传过的直接用 file_id），传不上就内联发送；文件过期时自动改内联重试一次。点消息里的图看大图
- 语音输入：输入框没字时右下角是麦克风，点了弹出手机自带的语音识别（中文 / 英文跟着 App 语言），说完的文字接在输入框后面，看一眼再发；手机没有语音识别服务时提示改用输入法的语音输入
- 朗读：用 DeepSeek 的语音合成（`/v1/tools/tts`，和对话同一个 Key，按字数计费），边合成边放（24 kHz PCM）；回复下面点喇叭念、再点停；顶栏喇叭是「自动朗读」开关，开了以后回复一边生成一边念（WebSocket 流式合成，有字了才连，超过一个会话的 1 万计费字符或 60 秒没字被断开就接着开下一个会话；按了停止，已经写出来的念完为止）；角色可以在编辑页单独设音色（跟着角色卡导出导入）；设置 → 语音 选女声（stella）/ 男声（tide），选了念一句试听；长回复按段落、句子切成几段依次念，代码块不念
- 上传文档：输入框「+」→ 文件，一条消息最多 10 个。PDF、Word、PPT 用 DeepSeek 文件解析（`text_recognition`，只取文字，按页收解析费，最大 100 MB / 1000 页）；Excel、CSV、EPUB、txt、json、Markdown、代码当文字传（`user_data`，不收解析费，最大 32 MB）；zip 在本机解压：文本和代码文件按路径合成一份（最多 6 MB，每段前标出路径），PDF、Word、PPT、表格、电子书单独传，图片和二进制跳过，隐藏目录（.git 等）和 __MACOSX 不要，GBK 文件名、GBK 文本都认得。选完马上上传，等解析好才能发（最多约 2 分钟）；之后每轮只发 file_id，文档全文一直在上下文里（按输入 token 计费）。服务端文件不设过期，删对话时一起删
- 智能搜索：用官方的 `deepseek_web_search`，搜索在 DeepSeek 服务端跑；回答下面列出引用的网页，点开用浏览器看
- 读链接：消息里贴网址，模型会自己去读（`deepseek_read_url`，一直开着）
- 自动标题：新对话的标题由模型顺手起
- 侧边栏：历史记录按时间分组、搜索、重命名、删除、多选删除
- 角色扮演：侧边栏「角色扮演」。角色卡有名字、头像、人设、开场白、性格、场景、示例对话、额外要求和创意度（temperature）；内置 4 个原创示例角色；能导入「酒馆」（SillyTavern）的 PNG / JSON 角色卡（V1 / V2 / V3）；编辑页能把角色导出成 PNG 角色卡（头像图里同时藏 V2 的 chara 和 V3 的 ccv3，世界书、创意度一起带上，没头像就画一张首字图；头像另存一份最大 1024 像素的大图专门用来导出，之前设的头像只有 256 的小图，重新选一次就有大图），世界书也能单独导出成酒馆世界书 JSON；世界书：卡里的 character_book 一起导入，也能单独导入酒馆世界书 JSON、在 App 里增删改，最近几条消息提到关键词（支持正则、次要关键词、递归）时把对应设定放进系统提示，「始终生效」的每次都带；「我的设定」所有角色都知道。角色对话默认不带工具（带工具时创意度不生效），深度思考、联网按对话单独开关
- 长期记忆：角色对话里没整理的部分超过约 2.4 万字时，把最近 16 条以前的内容让模型整理成「前情回忆」，之后只发回忆 + 最近对话；顶栏点角色名能看、能改、能马上整理
- 导入历史对话：设置 → 数据管理 → 导入 DeepSeek 历史对话，选官方 App / 网页「导出所有历史对话」得到的 `deepseek_data-*.zip`（格式 v3，照 DeepSeek 开源的 chat-demo）。合并进现有对话，同一对话再导入会更新；分支只留最后停留的那条线；图片、文件只留文件名；出错、被拒的轮次不进上下文
- 备份和恢复：设置 → 数据管理。所有对话（含图片）、角色（含头像、世界书）、「我的设定」、聊天背景和设置打成一个 zip；API Key 不进备份。恢复会整个替换现有数据（先确认），图片路径按这台手机重新对上
- 检查更新：设置里点版本号，是一个留着放联系方式的页面（在 `Strings.contact` 填）
- 设置：API Key、外观（系统 / 浅色 / 深色）、字体大小、语言（简体中文 / English）、清空对话
- 个性化：自定义聊天背景图，可调遮罩浓度和模糊（模糊要 Android 12 以上）
